프로젝트 소개

Local Document Organizer Agent는 사용자가 보유한 문서를 더 쉽게 정리할 수 있도록 만든 AI 기반 문서 관리 도구입니다.

프로젝트를 진행하다 보면 README, 기획서, 학습자료, 포트폴리오, TODO 문서처럼 다양한 파일이 계속 쌓입니다. 시간이 지나면 어떤 파일이 최신인지, 어떤 문서가 어떤 프로젝트에 해당하는지 헷갈리기 쉽습니다.

이 프로젝트는 문서를 업로드하면 AI가 문서 내용을 분석해 정리 기준을 자동으로 제안합니다.

핵심 기능

1

문서 유형 분류

문서의 문장, 키워드, 구조를 참고해 README, 기획서, 학습자료, 포트폴리오 등으로 분류합니다.

2

요약·키워드·추천 파일명 생성

문서의 핵심 내용을 요약하고 중요한 키워드와 정리하기 쉬운 파일명을 제안합니다.

3

중복 후보와 Markdown 리포트

여러 문서 간 유사도를 비교하고, 분석 결과를 Markdown 리포트로 정리합니다.

사용 흐름

사용자는 문서를 업로드하기만 하면, 시스템이 텍스트 추출부터 결과 리포트 생성까지 순서대로 처리합니다.

01 Upload TXT, Markdown, PDF 문서를 웹 화면에서 업로드합니다.
02 Extract 문서에서 텍스트를 추출하고 분석 가능한 형태로 변환합니다.
03 Analyze 문서 유형, 핵심 키워드, 요약, 추천 파일명을 생성합니다.
04 Report 중복 후보와 최종 분석 결과를 화면과 Markdown 리포트로 제공합니다.

기술 구성

외부 API에 의존하기보다 로컬 임베딩 모델과 규칙 기반 보정을 결합해 문서 정리 기능을 구현했습니다.

Streamlit Python PyMuPDF SentenceTransformer Local Embedding Text Similarity Extractive Summary Markdown Report

프로젝트의 특징

일반적인 파일 관리 도구는 파일명, 확장자, 생성일, 수정일을 기준으로 문서를 보여줍니다. 하지만 이 프로젝트는 문서의 실제 내용을 분석해 문서 유형, 핵심 키워드, 요약, 추천 파일명, 중복 후보를 함께 제공합니다.

따라서 문서를 하나씩 열어보지 않아도 어떤 문서인지 빠르게 파악하고 정리 방향을 잡을 수 있습니다.

기대 효과

  • 프로젝트별 README와 문서가 여러 개 쌓였을 때 빠르게 정리할 수 있습니다.
  • 과제 자료와 학습 노트를 문서 유형별로 파악할 수 있습니다.
  • 포트폴리오나 자기소개서 초안처럼 여러 버전으로 나뉜 문서를 비교할 수 있습니다.
  • 문서 내용을 바탕으로 더 적절한 파일명을 정할 수 있습니다.

한계와 개선 방향

현재 한계

PDF에서 텍스트가 제대로 추출되지 않는 경우 분석 품질이 떨어질 수 있습니다. 또한 추천 파일명과 문서 유형은 사용자가 최종 확인해야 하는 보조 결과입니다.

개선 방향

OCR 추가, 사용자 정의 문서 유형, 프로젝트별 폴더 추천, CSV/JSON 저장, 여러 문서 비교 대시보드 기능으로 확장할 수 있습니다.
