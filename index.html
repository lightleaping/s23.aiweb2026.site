HF 모델 매시업 또는 자유 구성형 AI 웹 프로젝트

인프라

웹 소개 페이지와 실행 데모 페이지를 분리해 구성

핵심 목표

문서를 하나씩 열어보지 않아도 정리 방향을 빠르게 파악

한 줄 요약

사용자가 TXT, Markdown, PDF 문서를 업로드하면 AI가 문서 유형, 핵심 키워드, 요약, 추천 파일명, 중복 후보를 분석해 문서 정리를 도와주는 웹 애플리케이션입니다.

문제

프로젝트와 과제를 진행하다 보면 README, 기획서, 학습자료, 포트폴리오, TODO 문서처럼 다양한 파일이 계속 쌓입니다.

시간이 지나면 파일명만 보고는 어떤 문서가 최신인지, 어떤 프로젝트에 해당하는지, 비슷한 문서가 중복으로 존재하는지 파악하기 어렵습니다.

이 프로젝트는 문서 내용을 AI가 분석해 사용자가 더 빠르고 체계적으로 파일을 정리할 수 있도록 돕습니다.

사용자

주 사용자는 과제, 프로젝트, 포트폴리오, 학습 자료를 자주 정리해야 하는 학생 또는 신입 개발자입니다.

여러 개의 README, PDF, Markdown 파일을 관리하면서 문서의 성격과 핵심 내용을 빠르게 파악하고 싶은 사용자를 대상으로 합니다.

핵심 기능

1

문서 유형 분류

문서 내용과 구조를 바탕으로 README, 기획서, 학습자료, 포트폴리오, TODO 등으로 분류합니다.

2

핵심 키워드·요약·추천 파일명 생성

문서에서 중요한 표현을 추출하고, 주요 내용을 요약하며, 정리하기 쉬운 파일명을 제안합니다.

3

중복 후보 탐지 및 Markdown 리포트

여러 문서 간 유사도를 비교해 중복 후보를 표시하고, 전체 분석 결과를 Markdown 리포트로 제공합니다.

입력 → AI 처리 → 출력

01 입력 사용자가 TXT, Markdown, PDF 문서를 업로드합니다.
02 텍스트 추출 문서에서 텍스트를 추출하고 분석 가능한 형태로 변환합니다.
03 AI 처리 문서 유형 분류, 키워드 추출, 요약, 추천 파일명 생성을 수행합니다.
04 출력 분석 결과와 중복 후보, Markdown 리포트를 화면에 표시합니다.

기술 스택

Streamlit Python PyMuPDF SentenceTransformer Local Embedding Text Similarity Extractive Summary Markdown Report

데이터 출처

사용자가 직접 업로드하는 TXT, Markdown, PDF 문서를 입력 데이터로 사용합니다. 테스트용 문서는 본인이 작성한 프로젝트 README, 학습자료, 기획서, 포트폴리오 문서 등을 사용합니다.

저작권 또는 개인정보 문제가 있는 문서는 사용하지 않으며, 기본 모드에서는 외부 API로 문서 내용이 전송되지 않도록 구성했습니다.

완료 조건

앱 실행 후 TXT, Markdown, PDF 샘플 문서를 업로드하면 각 문서에 대해 문서 유형, 핵심 키워드, 요약, 추천 파일명, 중복 후보 여부, Markdown 리포트가 화면에 출력됩니다.
