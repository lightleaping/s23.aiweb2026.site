정리 보조

추천 파일명과 중복 후보를 제안해 문서 관리 시간을 줄이는 것을 목표로 합니다.

프로젝트 소개

Local Document Organizer Agent는 사용자가 보유한 문서를 더 쉽게 정리할 수 있도록 만든 AI 기반 문서 관리 도구입니다.

프로젝트를 진행하다 보면 README, 기획서, 학습자료, 포트폴리오, TODO 문서처럼 다양한 파일이 계속 쌓입니다. 처음에는 파일명을 보고 구분할 수 있지만, 시간이 지나면 어떤 문서가 최신인지, 어떤 파일이 어떤 프로젝트에 해당하는지 헷갈리기 쉽습니다.

이 프로젝트는 문서를 업로드하면 AI가 문서의 내용을 분석해 문서 유형, 핵심 키워드, 요약, 추천 파일명, 중복 후보를 자동으로 제안하도록 만들었습니다.

제작 배경

개발 프로젝트와 과제를 진행하면서 여러 문서가 계속 생성되었습니다. 프로젝트마다 README가 있고, 수업 자료와 과제 정리 파일, 자기소개서나 포트폴리오 초안, 기능 설명 문서가 따로 존재합니다.

하지만 시간이 지나면 파일을 하나씩 열어 보기 전까지 어떤 내용인지 확인하기 어렵습니다. 그래서 문서를 업로드하면 AI가 자동으로 내용을 파악하고 정리 기준을 제안해 주는 웹 애플리케이션을 만들고자 했습니다.

주요 기능

  • 문서 업로드 및 텍스트 추출: TXT, Markdown, PDF 문서를 업로드하고 분석 가능한 텍스트로 변환합니다.
  • 문서 유형 분류: 문서 내용과 구조를 바탕으로 README, 기획서, 학습자료, 포트폴리오, TODO 등으로 분류합니다.
  • 핵심 키워드 추출: 문서의 중요한 단어나 표현을 추출해 핵심 주제를 빠르게 확인할 수 있습니다.
  • 문서 요약: 문서의 주요 내용을 짧게 요약해 파일을 열어보지 않아도 내용을 파악할 수 있습니다.
  • 추천 파일명 생성: 문서 내용과 유형을 반영한 파일명을 제안합니다.
  • 중복 후보 탐지: 여러 문서 간 유사도를 비교해 비슷한 문서를 중복 후보로 표시합니다.
  • Markdown 리포트 생성: 분석 결과를 Markdown 형식으로 정리해 저장하거나 재사용할 수 있습니다.

사용 흐름

1. 사용자가 TXT, Markdown, PDF 문서를 업로드합니다.
2. 시스템이 문서에서 텍스트를 추출합니다.
3. 추출된 텍스트를 기반으로 문서 유형을 분류합니다.
4. 핵심 키워드와 요약을 생성합니다.
5. 문서 내용에 맞는 추천 파일명을 제안합니다.
6. 여러 문서가 있을 경우 유사도를 비교해 중복 후보를 찾습니다.
7. 최종 결과를 웹 화면과 Markdown 리포트로 제공합니다.

기술 구성

  • UI: Streamlit
  • Language: Python
  • 문서 처리: TXT, Markdown, PDF 텍스트 추출
  • PDF 처리: PyMuPDF
  • AI 모델: SentenceTransformer 기반 로컬 임베딩 모델
  • 문서 분류: 임베딩 유사도 + 규칙 기반 보정
  • 요약 방식: 문서 핵심 문장 기반 추출형 요약
  • 결과 출력: Streamlit 화면 + Markdown 리포트

프로젝트의 특징

이 프로젝트의 가장 큰 특징은 문서 내용을 이해한 뒤 정리 기준을 제안하는 도구라는 점입니다. 일반적인 파일 관리 도구는 파일명, 확장자, 생성일, 수정일을 기준으로 문서를 보여줍니다. 하지만 이 프로젝트는 문서의 실제 내용을 분석해 문서 유형, 핵심 키워드, 요약, 추천 파일명, 중복 후보를 함께 제공합니다.

또한 외부 API에 의존하지 않고 로컬 모델 중심으로 구성할 수 있어, 개인 문서를 다루는 상황에서도 비교적 안전하게 사용할 수 있습니다.

기대 효과

  • 프로젝트별 README와 문서가 여러 개 쌓였을 때 빠르게 정리할 수 있습니다.
  • 과제 자료와 학습 노트를 문서 유형별로 파악할 수 있습니다.
  • 포트폴리오나 자기소개서 초안처럼 여러 버전으로 나뉜 문서를 비교할 수 있습니다.
  • 비슷한 내용의 문서를 찾고 중복 후보를 정리할 수 있습니다.
  • 문서 내용을 바탕으로 더 적절한 파일명을 정할 수 있습니다.

한계와 개선 방향

현재 프로젝트는 문서 텍스트를 기반으로 분석하기 때문에, PDF에서 텍스트가 제대로 추출되지 않는 경우 분석 품질이 떨어질 수 있습니다. 또한 문서 유형 분류와 추천 파일명은 사용자가 최종적으로 확인하고 보완하는 보조 결과로 보는 것이 적절합니다.

  • OCR 기능을 추가해 이미지 기반 PDF도 분석 가능하게 개선
  • 사용자가 직접 문서 유형 기준을 추가할 수 있도록 개선
  • 프로젝트별 폴더 추천 기능 추가
  • 분석 결과를 CSV 또는 JSON으로 저장
  • 여러 문서를 한 번에 비교하는 대시보드 기능 추가

마무리

Local Document Organizer Agent는 단순한 파일 업로드 웹앱이 아니라, 사용자의 문서 정리 과정을 AI가 도와주는 문서 관리 보조 도구입니다.

문서를 읽고, 분류하고, 요약하고, 이름을 추천하고, 중복 가능성까지 확인하는 흐름을 하나의 웹 애플리케이션으로 연결했습니다.
